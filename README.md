# 腕记同步

AstroBox 插件，配合手环上的「腕记」记事本使用。

- **读取**手环上的全部记事
- **复制**一条或全部记事到剪贴板
- **导出**成 Markdown 文件
- **发到手环**：在手机或电脑上写好一段文字，发过去手环上会多出一条记事（长文会自动分片）

## 用法

1. 在 AstroBox 里给手环装好「腕记」（资源商店里搜「腕记」）。
2. 在 AstroBox 的插件商店里装「腕记同步」，并按提示给权限。
3. 在手环上打开腕记，保持亮屏，然后在插件里点「读取」。

记事只在手环和你的手机、电脑之间传，不经过任何服务器。

## 目录

`index.txt` 指向 `release/`，里面是插件的 `manifest.json`、图标和编译好的 `wristnote_sync.wasm`（Rust，AstroBox 插件 API Level 3）。
